# Archivio

Lokale Suche für Architekturbüros: Dokumente, Pläne und Mails auf dem
Büro-Server durchsuchen, ohne Cloud. Kostenlos, mit KI-Schnittstelle als
Filter zwischen KI und Büro-Server.

- Website und Download: [modulario.ch](https://modulario.ch)
- Demo: [demo-archivio.modulario.ch](https://demo-archivio.modulario.ch)
- Installationspakete: [Releases](https://github.com/inderfab/archivio/releases)

Dieses Repository enthält die Website (Ordner `docs/`, ausgeliefert über
GitHub Pages) und die Releases. Der Quellcode von Archivio ist nicht öffentlich.
