Mail-Integration

Postfach aktivieren/deaktivieren: Schalter links neben dem Postfach.

Projekt-Zuordnung, automatisch: Enthält der Postfach-/Ordnername eine Projektnummer (z. B. „123_Projektname"), wird das passende Projekt automatisch zugeordnet, sobald „Postfächer aktualisieren" läuft — ohne Bestätigung nötig.

Vorschlag statt Automatik: Findet sich keine Nummer, aber Namen überschneiden sich mit einem Projekt, erscheint stattdessen nur ein Vorschlag — der wird nie automatisch übernommen, sondern muss per „Übernehmen" bestätigt werden.

Manuell: Über das Dropdown jederzeit änderbar, auch nachträglich. „+ Als eigenes Projekt speichern" macht aus einem Postfach ohne passenden Ordner ein eigenständiges Projekt.

MCP-Freigabe (☁): Ist das Postfach einem Projekt zugeordnet, übernimmt es dessen Freigabe-Status (hier nicht separat einstellbar). Nur bei aktiven, noch nicht zugeordneten Postfächern gibt es einen eigenen Schalter.

Archiviert (📦): Wie bei Projekten (siehe Projektliste) — ein archiviertes Postfach wird seltener auf neue Mails geprüft. Ist das Postfach einem Projekt zugeordnet, übernimmt es dessen Archiv-Status, genau wie bei der MCP-Freigabe.
