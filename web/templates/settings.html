{# ── Mitarbeiter-Setup ── #}
▶ Mitarbeiter-Setup

Der Archivio Helper ist eine kleine macOS Menubar-App für Mitarbeiter-Macs. Sie ermöglicht das Öffnen von Dateien direkt aus dem Browser via archivio://-Link.

{% if helper_available %} ⬇ Helper herunterladen (v{{ helper_version }})

Nach dem Download: Installer öffnen und den Anweisungen folgen (Admin-Passwort nötig). Die App landet dabei automatisch für alle Benutzer des Macs in Programme — wichtig bei mehreren Accounts auf einem Gerät.
Beim ersten Start werden Abhängigkeiten installiert (ca. 1–2 Min.).
Der Helper findet den Server normalerweise automatisch im Netzwerk. Falls nicht, im Helper-Menü unter „Server suchen" oder „Server ändern" manuell eintragen: {{ helper_url_hint }}

{% else %}

Noch kein Build vorhanden — bash helper/build.sh ausführen.

{% endif %}

Datei-Link teilen ("Archivio-Link kopieren"): Server und Helper installieren dafür automatisch eine Schnellaktion im Finder. Damit kann jede Kollegin/jeder Kollege mit installiertem Helper eine Datei direkt öffnen, ohne selbst im Archivio-NAS-Ordner danach suchen zu müssen.

  1. Datei im Finder mit Rechtsklick auswählen
  2. Schnellaktionen (bzw. Quick Actions) → „Archivio-Link kopieren"
  3. Link ist in der Zwischenablage — z.B. in eine Mail oder einen Chat einfügen
  4. Empfänger:in mit installiertem Archivio Helper klickt den Link → Datei öffnet sich bzw. wird im Finder angezeigt (je nach Voreinstellung im Helper-Menü)

Der Klick öffnet die Datei sofort bzw. zeigt sie im Finder — je nachdem, was die klickende Person im eigenen Helper-/Server-Menü unter „Archivio-Links: Direkt öffnen"/„Zum Pfad gehen" eingestellt hat. Mail/Messages zeigen beim Einfügen des Links eine Vorschau mit dem Dateinamen an.
