    KI-Schnittstelle (MCP) einrichten

    Der KI-Dienst sucht über eine Programmschnittstelle in der Archivio-Datenbank. Die Suchresultate werden als Dokumentfragmente an das KI-Programm übergeben. Diese Fragmente werden je nach Anbieter lokal oder in der Cloud verarbeitet.

    Jede Arbeitsstation, die MCP nutzen will, muss zum einen den Archivio Helper installieren und zum anderen die MCP-Schnittstelle einrichten. Unterstützt werden bewusst nur Anwendungen, die MCP über eine lokale Konfigurationsdatei einbinden (aktuell Claude Desktop). Claude braucht dafür keinen Internetzugriff auf die Archivio-Datenbank. Nach der Installation Claude Desktop einmal neu starten, damit die Verbindung aktiv wird.

    ChatGPT funktioniert anders: dort läuft MCP in der OpenAI-Cloud und braucht eine Internetverbindung zum Server — die Daten werden nicht lokal, sondern auf einem fremden Server verarbeitet. Aus Datenschutz-/Urheberrechtsgründen ist das deshalb zurzeit nicht freigegeben. Bei Interesse bitte Feedback senden.

    Welche Projekte MCP überhaupt sehen darf, wird pro Projekt in „Projekte" freigegeben (☁-Symbol) — standardmässig ist keines freigegeben, ohne Freigabe liefert die Verbindung keine Treffer. Verwaltung der Sperrliste und Protokoll aller Zugriffe unter „Verwaltung → Verlauf"/„Sperrliste". Erkannte Normen werden nie übermittelt.

    Bei Claude kann in den Einstellungen konfiguriert werden, dass Chats nicht fürs Modelltraining verwendet werden. Trotzdem werden die Suchfragmente auf dem Server des Anbieters verarbeitet. Die aktive Sperrliste und die automatische Normen-Erkennung verhindern, dass Datenschutz und Urheberrecht verletzt werden — dafür ist aber eine aktive Mitarbeit der Nutzenden nötig.

    Datei-Link teilen

    Server und Helper installieren automatisch eine Finder-Erweiterung. Je nach Mac erscheint sie im Rechtsklick-Menü unter „Schnellaktionen" oder unter „Dienste" — beides ist derselbe Befehl.

    Mail und Messages zeigen beim Einfügen des Links eine Vorschau mit dem Datei-/Ordnernamen an.

    Ob ein geöffneter Link die Datei direkt öffnet oder im Finder zeigt, stellt jede Person für sich im eigenen Helper-Menü ein.

    Mit dieser Funktion können bürointern Dateien „versendet" werden — es sind jedoch keine Kopien, sondern der Link zum Originaldokument auf dem Server.
