Helper

Menubar-App für macOS. Fürs ganze Büro muss nur ein Server laufen, alle Mitarbeiter brauchen nur den Helper. Damit können Sie Suchresultate in Archivio direkt öffnen, die MCP-Schnittstelle zur KI-Anwendung nutzen und Archivio- Dateilinks versenden.

{% if helper_available %} ⬇ Helper herunterladen (v{{ helper_version }})

Installer öffnen und den Anweisungen folgen (Admin-Passwort nötig). Der erste Start dauert ein bis zwei Minuten.

Den Server findet der Helper normalerweise selbst. Falls nicht: Helper-Menü → „Server suchen" oder „Server ändern" → {{ helper_url_hint }}

{% else %}

Noch kein Build vorhanden — bash helper/build.sh ausführen.

{% endif %}

Datei-Link teilen

  1. Rechtsklick auf die Datei im Finder
  2. Schnellaktionen → „Archivio-Link kopieren"
  3. Link einfügen, z. B. in Mail oder Chat
  4. Empfänger mit installiertem Helper klickt darauf — die Datei öffnet sich oder wird im Finder gezeigt, je nach eigener Einstellung im Helper-Menü
