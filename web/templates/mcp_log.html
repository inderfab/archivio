    MCP

    MCP (Model Context Protocol) ist der offene Standard, über den KI-Anwendungen wie Claude Desktop direkt auf Archivio zugreifen. Hier wird die Schnittstelle eingerichtet, gesteuert, welche Inhalte nie übermittelt werden dürfen, und protokolliert, was tatsächlich übermittelt wurde.

    MCP-Schnittstelle

    Läuft nur lokal auf diesem Rechner über den Archivio Helper (bzw. den Archivio Server, falls dieser hier direkt läuft) — es wird nichts an einen Cloud-Dienst übertragen.

    Unterstützt werden bewusst nur Anwendungen, die MCP über eine lokale Konfigurationsdatei einbinden (aktuell Claude Desktop). Cloud-Connectoren wie ChatGPT oder Perplexity verlangen stattdessen eine von aussen erreichbare Adresse und werden hier deshalb nicht angeboten — das würde bedeuten, den Server aus dem Büronetz herauszugeben.

    Sperrliste

    Ergänzt die automatische Norm-Erkennung um von Hand gesetzte Regeln: einzelne Dateien, Namens-Muster, ganze Ordner oder Projekte werden nie über MCP ausgegeben — lokal bleiben sie weiterhin durchsuchbar.

    Ein Namens-Muster (z. B. *Lohn*) prüft sowohl den Dateinamen als auch den vollen Pfad.

    Wildcard-Syntax für Namens-Muster und Ordner: *xx* — enthält „xx" irgendwo; xx* — beginnt mit „xx" (trifft NICHT „vorxx"); nur xx ohne Stern — ausschliesslich der exakt gleichnamige Ordner/Datei.
