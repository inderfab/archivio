Archivio Helper

macOS Menubar-App für Mitarbeiter

Der Archivio Helper läuft im Hintergrund und ermöglicht das Öffnen von Dateien direkt aus dem Browser via archivio://-Link.

  • Läuft im macOS Menubar
  • Öffnet Dateien direkt auf dem NAS mit der richtigen App
  • Optional: automatischer Start beim Login
  • Zeigt Verbindungsstatus zum Archivio-Server
