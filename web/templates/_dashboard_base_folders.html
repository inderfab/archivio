Jeder hier eingetragene Ordner wird durchsucht — seine direkten Unterordner erscheinen unten automatisch als eigene Projekte. Ohne mindestens einen eingetragenen Ordner findet die Suche keine Dokumente.

Liegt der Ordner auf einem Datei-Server/NAS, diesen vorher im Finder einhängen (⌘K „Mit Server verbinden") — am besten so einrichten, dass er beim Start dieses Macs automatisch verbunden wird (macOS-Systemeinstellungen → „Anmeldeobjekte").

Einen Ordner entfernen deaktiviert automatisch alle daraus entdeckten Projekte — ihre Dokumente bleiben in der Datenbank, bis sie einzeln endgültig gelöscht werden.
