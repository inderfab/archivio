Datenschutzerklärung

Diese Erklärung betrifft die Website architools.ch und den Download von Archivio. Was die installierte App mit den Daten eures Büros macht, steht im Merkblatt zu euren Daten. Kurz: Die App läuft vollständig lokal, ohne Cloud und ohne Benutzerkonto.

Verantwortlich

architools, Fabio Indergand, Winterthur, Schweiz, info@architools.ch

Hosting der Website

Die Website wird über GitHub Pages (GitHub, Inc., USA) ausgeliefert. Beim Aufruf verarbeitet GitHub technisch notwendige Daten wie IP-Adresse, Zeitpunkt und aufgerufene Seite, um die Seite auszuliefern und vor Missbrauch zu schützen. Beim Laden der Startseite und beim Download fragt euer Browser zudem bei GitHub die aktuelle Programmversion ab. Es gelten die Datenschutzbestimmungen von GitHub.

Keine Cookies, kein Tracking von Besuchen

Die Website setzt keine Cookies, verwendet keine Analyse- oder Werbedienste und lädt keine Schriften oder Skripte von Drittanbietern.

E-Mail-Adresse beim Download

Für den Download wird eine E-Mail-Adresse abgefragt. Sie wird zusammen mit dem Zeitpunkt in einer Tabelle bei Google (Google Apps Script und Google Sheets) gespeichert und ausschliesslich verwendet, um über grössere Versions-Updates zu informieren. Sie wird nicht für Werbung genutzt und nicht an Dritte weitergegeben. Jede Update-Mail enthält einen Abmelde-Link; danach wird die Adresse aus der Liste entfernt. Zusätzlich wird pro Download die heruntergeladene Version gezählt, ohne Bezug zur Person.

Kontakt per E-Mail

Wenn ihr an info@architools.ch schreibt, werden eure Angaben nur zur Beantwortung der Anfrage verwendet.

Eure Rechte

Nach dem Schweizer Datenschutzgesetz könnt ihr jederzeit Auskunft über eure gespeicherten Daten verlangen sowie deren Berichtigung oder Löschung beantragen. Eine E-Mail an info@architools.ch genügt.
