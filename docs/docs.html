Installation

Archivio besteht aus zwei Teilen: dem Server, der auf einem fixen Mac (z. B. iMac) läuft, und dem optionalen Helper auf jedem Mitarbeiter-Mac.

Schritt 1 — Archivio Server installieren

  1. Das neuste .pkg von der Releases-Seite herunterladen.
  2. Doppelklick auf die .pkg-Datei — der Installer öffnet sich.
  3. Auf Fortfahren und dann Installieren klicken.
  4. Mac-Passwort eingeben und auf Software installieren klicken.
  5. Zwei Berechtigungsdialoge erscheinen — jeweils Erlauben klicken.
  6. „Die Installation war erfolgreich" — auf Schließen klicken.

Schritt 2 — Festplattenvollzugriff gewähren

Damit Archivio auf NAS-Volumes und Dokumente zugreifen kann, muss Archivio Server den Festplattenvollzugriff erhalten.

  1. Öffne Systemeinstellungen → Datenschutz & Sicherheit → Festplattenvollzugriff.
  2. Klicke auf + und wähle Archivio Server aus dem Ordner Programme.
  3. Starte Archivio Server neu — Menüleisten-Icon → Beenden → App wieder öffnen.

Sicherheitswarnung beim ersten Öffnen

Auf macOS Ventura und neuer kann macOS die App beim ersten Öffnen blockieren. So gehst du vor:

  1. Beim ersten Start erscheint der Hinweis, dass „Archivio Server.app" nicht geöffnet werden konnte. Klicke auf Fertig.
  2. Öffne Systemeinstellungen → Datenschutz & Sicherheit. Im Abschnitt „Sicherheit" erscheint die Meldung, dass die App blockiert wurde.
  3. Klicke dort auf Dennoch öffnen und bestätige mit deinem Mac-Passwort oder Touch ID.

Erster Start

Nach dem Start ist die Weboberfläche unter http://<Server-IP>:8000 erreichbar — z. B. http://192.168.1.10:8000.

Beim ersten Öffnen ist die Datenbank leer. Zuerst ein Projekt anlegen und den NAS-Ordner verknüpfen, dann einen ersten Scan starten.

NAS verknüpfen

Archivio liest Dateien direkt vom NAS. Das NAS muss auf dem Server-Mac eingehängt sein, bevor ein Scan läuft.

  1. Im Finder: Gehe zu → Mit Server verbinden (⌘K) → NAS-Adresse eingeben → verbinden.
  2. In der Archivio-Weboberfläche: Dashboard → Projekte → Neues Projekt.
  3. Projektname vergeben und den Pfad zum NAS-Ordner eintragen, z. B. /Volumes/NAS/Projekte/2024.
  4. Speichern → Scan starten.
Tipp: Der NAS-Ordner sollte beim Serverstart automatisch eingehängt sein. Das lässt sich in den macOS-Systemeinstellungen unter „Benutzer & Gruppen → Anmeldeobjekte" einrichten.

Unterordner als Projekte

Unterordner eines bestehenden Projekts können als eigene Sub-Projekte geführt werden — mit separatem Scan, eigenem Filter und eigener Dokumentenliste.

  1. Im Dashboard die Browse-Ansicht des übergeordneten Projekts öffnen.
  2. Den gewünschten Unterordner anklicken — rechts erscheint das Detailpanel.
  3. Auf „Diesen Ordner als eigenes Projekt" klicken.
  4. Der Unterordner erscheint jetzt in der Projektliste und kann separat gescannt und durchsucht werden.
Tipp: Dokumente, die vor der Sub-Projekt-Erstellung bereits indiziert wurden, tauchen auch bei einer Suche innerhalb des Sub-Projekts auf — Archivio erkennt sie anhand des Dateipfads. Um ein Sub-Projekt wieder aufzulösen, auf „Nicht mehr als eigenes Projekt" klicken.

Ordner ignorieren

Temporäre Ordner, Papierkorb oder Archive können vom Scan ausgeschlossen werden. Die Steuerung erfolgt direkt in der Browse-Ansicht des Dashboards — keine Einstellungsseite nötig.

Einzelnen Ordner ignorieren

  1. Im Dashboard die Browse-Ansicht des Projekts öffnen und den Ordner anklicken.
  2. Im Detailpanel auf „Ignorieren" klicken.
  3. Der Ordner wird beim nächsten Scan übersprungen und in der Browse-Liste als ignoriert markiert.

Alle Ordner einer Ebene auf einmal ignorieren

  1. Einen beliebigen Ordner auf der gewünschten Ebene anklicken.
  2. Im Detailpanel auf „Alle Ordner auf dieser Ebene ignorieren" klicken und bestätigen.
  3. Alle Geschwister-Ordner werden auf einmal ausgeschlossen.

Ignorierung aufheben

Einen ignorierten Ordner anklicken — im Detailpanel erscheint „Ignorierung aufheben" (für diesen Ordner allein) oder „Alle Ordner auf dieser Ebene Ignorierung aufheben" (für alle Geschwister auf einmal).

Mitarbeiter-Macs einrichten

Der Archivio Helper läuft auf jedem Mitarbeiter-Mac als kleines Menüleisten-Icon. Er ermöglicht das Öffnen von Dateien direkt aus der Suchoberfläche.

  1. Auf dem Mitarbeiter-Mac die Archivio-Weboberfläche öffnen: http://<Server-IP>:8000.
  2. Oben rechts: Helper herunterladen → .zip entpacken.
  3. „Archivio Helper" in den Programme-Ordner ziehen und starten.
  4. Im Helper-Menü die Server-URL eintragen. Die korrekte URL steht in der Archivio-Weboberfläche unter Einstellungen → ganz unten, im Abschnitt „Archivio Helper".
  5. „Autostart beim Login" aktivieren.

Ab jetzt erscheinen in den Suchergebnissen „Öffnen"- und „Im Finder zeigen"-Buttons, die Dateien direkt auf dem Mitarbeiter-Mac öffnen.

Festplattenvollzugriff für den Helper

Damit der Helper Dateien auf Netzlaufwerken (NAS) direkt öffnen und im Finder anzeigen kann, muss auch Archivio Helper den Festplattenvollzugriff erhalten.

  1. Öffne Systemeinstellungen → Datenschutz & Sicherheit → Festplattenvollzugriff.
  2. Klicke auf + und wähle Archivio Helper aus dem Programme-Ordner.
  3. Helper neu starten.
Hinweis: Genau wie beim Server reicht ein einziger Eintrag — der Helper enthält alle nötigen Komponenten direkt im App-Bundle.

Suche

Die Volltextsuche findet Inhalte in PDFs, Word-Dokumenten, E-Mails und weiteren Formaten. Die Suche unterstützt:

  • Einzelwörter — Brandschutz
  • Phrasen — "Technischer Bericht"
  • Mehrere Begriffe — alle eingegebenen Wörter müssen vorkommen

Suchbereich einschränken

Unterhalb des Suchfelds stehen drei Scope-Buttons, die festlegen, wo gesucht wird:

  • Dokumente — durchsucht den vollständigen Textinhalt aller indizierten Dokumente (Standard).
  • Ordnernamen — sucht ausschliesslich in den Ordnernamen auf dem NAS. Nützlich um Projekte oder Ablageorte schnell zu finden.
  • Dateinamen — sucht ausschliesslich im Dateinamen. Nur Dateien, deren Name den Begriff enthält, werden angezeigt — Dokumente, die den Begriff nur im Inhalt haben, werden nicht gelistet.

Mehrere Bereiche können gleichzeitig aktiv sein. Über die weiteren Filter lässt sich die Suche zusätzlich auf bestimmte Projekte, Dateitypen oder Zeiträume einschränken.

KI-Suche aktivieren

Die KI-Suche beantwortet Fragen auf Basis der indizierten Dokumente — ohne Cloud, vollständig lokal.

Voraussetzung: Ollama installieren

Ollama wird direkt aus Archivio heraus installiert — kein manuelles Herunterladen nötig.

  1. KI-Suche öffnen. Falls Ollama fehlt, erscheint die Meldung „KI-Suche nicht verfügbar" mit einem Button „Ollama jetzt installieren".
  2. Button klicken — Archivio führt brew install ollama automatisch aus. Der Fortschritt wird direkt angezeigt.
  3. Nach erfolgreicher Installation: Archivio Server neu starten. Er lädt das Sprachmodell automatisch beim ersten Start.
Wichtig: Ollama muss per Terminal installiert werden — die Ollama.app von ollama.com funktioniert nicht, da sie keine Terminal-Verbindung herstellt. Archivio installiert Ollama korrekt per Button automatisch.

Manuelle Installation (Alternative)

Ollama lässt sich auch manuell installieren: Das Programm Terminal öffnen, folgenden Befehl reinkopieren und mit Enter bestätigen:

curl -fsSL https://ollama.com/install.sh | sh

Danach Archivio Server neu starten.

KI-Suche verwenden

Im Suchfeld oben den Tab „KI-Suche" wählen und eine Frage in ganzen Sätzen stellen, z. B.: „Welche Anforderungen gelten für den Brandschutz im Treppenhaus?"

Archivio sucht die relevantesten Textstellen und formuliert eine Antwort mit Quellenangaben.

Automatischer Scan

Damit neue Dateien auf dem NAS automatisch gefunden werden, kann ein täglicher Scan eingerichtet werden.

  1. Dashboard → Einstellungen öffnen.
  2. Im Abschnitt „Automatischer Scan" eine Uhrzeit eintragen, z. B. 02:00.
  3. Speichern. Der Scan läuft täglich zur eingestellten Zeit — vorausgesetzt, der Server läuft.
Manueller Scan: Im Dashboard kann jederzeit ein Scan per Knopfdruck gestartet werden. Bei grossen NAS-Ordnern dauert der erste Scan einige Stunden.
