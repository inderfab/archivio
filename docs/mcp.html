Archivio MCP-Schnittstelle für Claude Desktop

Über die MCP-Schnittstelle (Model Context Protocol) kann ein KI-Assistent wie Claude Desktop in Archivio suchen und gefundene Dokumente lesen. So lassen sich Fragen zu Projektunterlagen direkt im Chat stellen, ohne Dateien von Hand hochzuladen. Die Schnittstelle ist optional und standardmässig ausgeschaltet.

Kurz: Der MCP-Server läuft lokal auf dem Arbeitsplatz-Mac, zusammen mit dem Archivio Helper. Er fragt den Archivio-Server im Büronetz ab. Es gibt keine öffentliche Web-API und keinen Zugriff von aussen.

So funktioniert es

Claude Desktop startet den Archivio-MCP-Server als lokales Programm (stdio) auf dem eigenen Mac. Stellt jemand im Chat eine Frage, ruft Claude die Werkzeuge von Archivio auf, zum Beispiel eine Suche. Der MCP-Server leitet die Anfrage an den Archivio-Server im Büronetz weiter und gibt die Treffer an Claude zurück. Was dabei an Claude übermittelt wird, sind die Ausschnitte der Dokumente, die für die Frage abgerufen werden, und nur aus Projekten, die dafür freigegeben sind.

Voraussetzungen

  • Archivio ist im Büro auf dem Server-Mac installiert.
  • Auf dem Arbeitsplatz-Mac laufen der Archivio Helper und Claude Desktop.
  • Der Arbeitsplatz ist im Büronetz (Kabel oder Büro-WLAN).
  • Mindestens ein Projekt ist für KI-Anwendungen freigegeben.

Einrichtung

  1. Archivio im Browser öffnen und auf der Seite Helper den Archivio Helper installieren.
  2. Auf derselben Seite unter «KI-Schnittstelle (MCP) einrichten» Claude Desktop wählen und auf MCP-Schnittstelle installieren klicken. Der Helper trägt Archivio in die Konfiguration von Claude Desktop ein, andere Einträge bleiben unverändert.
  3. Claude Desktop neu starten. Danach erscheint Archivio in Claude unter den verbundenen Werkzeugen.
  4. In Archivio unter Projekte die gewünschten Projekte mit dem ☁-Symbol freigeben. Ohne Freigabe liefert die Schnittstelle keine Treffer.

Werkzeuge

Diese Werkzeuge stellt der Archivio-MCP-Server bereit. Der Servername in Claude Desktop ist archivio.

WerkzeugWas es tutWirkung
searchVolltextsuche in Dokumenten, Mails, Datei- und Ordnernamen, optional auf ein Projekt eingeschränkt. Jeder Treffer hat eine ID.nur lesend
read_documentLädt den Text eines gefundenen Dokuments blockweise in die Unterhaltung, zum Lesen, Zusammenfassen oder Beantworten von Fragen.nur lesend
list_folderListet den Inhalt eines Ordners innerhalb der Archivio-Projektordner.nur lesend
open_fileÖffnet eine Datei in der zugehörigen App auf dem eigenen Mac.nur lesend
reveal_fileZeigt eine Datei im Finder.nur lesend
merge_documents_to_pdfFügt mehrere gefundene PDFs zu einer neuen PDF-Datei im Downloads-Ordner zusammen.legt neue Datei an
copy_documents_to_folderKopiert die Originaldateien gefundener Dokumente in einen neuen Ordner im Downloads-Ordner. Die Originale bleiben unverändert.legt neue Dateien an

Die lesenden Werkzeuge sind gegenüber Claude als «nur lesend» gekennzeichnet. Dateien öffnen, im Finder zeigen und Ordner auflisten funktioniert nur innerhalb der Projektordner, die in Archivio konfiguriert sind.

Beispiele für Fragen

  • «Welche Bodenbeläge sind im Treppenhaus von Projekt 300 vorgesehen?»
  • «Fasse die Mails mit dem Sanitärplaner zur Materialwahl zusammen.»
  • «Erstelle mir ein PDF mit je einem Treppenhausplan pro Projekt.»
  • «Wo liegt die aktuelle Kostenschätzung für das Projekt Emmenhof?»

Datenschutz und Kontrolle

  • Freigabe pro Projekt: Neue Projekte sind nie automatisch für KI-Anwendungen sichtbar.
  • Sperrliste: Unter «Verwaltung → Sperrliste» lassen sich zusätzlich Ordner oder Dateien für die Schnittstelle sperren.
  • Normen: Als Norm erkannte Dokumente (SIA und weitere) werden nie übermittelt.
  • Protokoll: Jeder Zugriff und jede Blockierung wird unter «Verwaltung → Verlauf» festgehalten.

Für die Nutzung von Claude empfehlen wir ein Team- oder Enterprise-Konto. Details dazu im Merkblatt zu euren Daten.

Andere KI-Anwendungen

Unterstützt werden Anwendungen, die MCP-Server lokal über eine Konfigurationsdatei einbinden, aktuell Claude Desktop. ChatGPT bindet MCP-Server über die Cloud von OpenAI an und bräuchte dafür einen Zugang zum Archivio-Server aus dem Internet. Das ist aus Datenschutzgründen zurzeit nicht vorgesehen.
